# Kontrollfragen
1. Das Working Directory ist der Ordner auf der Festplatte. Die Staging Area ist der Zwischenspeicher für den nächsten Commit. Das Repository (.git) speichert die endgültige Versionsgeschichte.
2. Im Terminal steht "Fast-forward". Es wird kein neuer Merge-Commit erzeugt, der Zeiger rutscht einfach auf der Linie nach vorne.
3. Er schlägt fehl, wenn auf main in der Zwischenzeit neue Commits gemacht wurden (die Historie hat sich gespalten).
4. Man kann sicher experimentieren, ohne den funktionierenden Code auf main kaputt zu machen.
5. Mit 'git status' oder 'git branch'.
6. Stagen mit 'git add <datei>', dauerhaft speichern mit 'git commit -m "Nachricht"'.
